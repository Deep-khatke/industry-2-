# Tier-1 SOC Analyst Triage Runbook

## 1. Role & Objective
Tier-1 SOC Analysts are responsible for investigating candidate incidents generated by FCS-HMD, validating threat evidence, recording structured feedback dispositions, and submitting recommended defensive responses.

## 2. Standard Triage Workflow
1. **Incident Selection:**
   - Open the SOC Dashboard &rarr; **ISP Pilot Operations** &rarr; **D. Analyst Incident Review**.
   - Select candidate incident ID from the queue.
2. **Evidence Inspection:**
   - Check target IP and source IP.
   - Verify protocol (e.g. TCP SYN vs UDP high volume).
   - Review specialist prediction score and uncertainty flag.
3. **Assigning Structured Disposition:**
   - `TRUE_POSITIVE`: Confirmed malicious attack (DDoS, SYN flood, scanning).
   - `FALSE_POSITIVE`: Benign subscriber traffic incorrectly scored as anomalous.
   - `BENIGN_BUT_UNUSUAL`: Authorized large data transfers, automated backups, or speed tests.
   - `INCONCLUSIVE`: Ambiguous traffic requiring further packet telemetry.
   - `DUPLICATE`: Grouped under existing active incident.
4. **Recording Feedback:**
   - Record triage duration in seconds (target: $\le 240\text{s}$ per incident).
   - Enter detailed investigation notes.
   - Click **Submit Human Triage Disposition**.
